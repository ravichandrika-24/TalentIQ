# TalentIQ — AI-Powered Recruitment & Talent Intelligence Platform

TalentIQ is a modern recruitment platform designed to help recruiters discover, evaluate, rank, and manage candidates efficiently.

## 🚀 Features

- 🔐 Secure Recruiter Login
- 📊 Recruiter Dashboard
- 👥 Candidate Management
- 🔎 Candidate Search & Filtering
- 📄 Resume Management
- 🧠 AI-Based Skill Matching
- 🏆 Candidate Ranking
- 💼 Job Management
- 📈 Recruitment Analytics
- 🧩 Skill-Gap Analysis
- 📱 Responsive Recruiter Interface
- 🔒 Recruiter-only Page Protection

## 🛠️ Technology Stack

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- SQLite
- AI/Matching Algorithms
- Data Structures & Algorithms

## 👩‍💻 Project Purpose

TalentIQ helps recruiters reduce manual candidate screening by combining candidate information, skills, job requirements, matching algorithms, and analytics into one platform.

## 🔐 Recruiter Access

All recruiter pages are protected and can only be accessed after recruiter authentication.

## 📂 Main Components

- `app.py` — Application and routes
- `database.py` — Database operations
- `matcher.py` — Candidate/job matching
- `analytics.py` — Recruitment analytics
- `dsa.py` — Ranking and algorithmic operations
- `seed.py` — Initial data
- `schema.sql` — Database schema
- `templates/` — Web interface

## 🌐 Live Application

TalentIQ is deployed online and can be tested through the deployed application.
